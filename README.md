WeatherClock2.ino draws its weather data openweathermap.org. If using this file you will need to add your own openweathermap.org API key into the .ino file. Search for "const char* OWM_API_KEY = "insert your key here";" in the file.
OpenMeteoClock.ino draws its weather data from Open-Meteo.com and does not require a key.
Each sketch includes an attribution banner crediting the respective data sources as required by each provider's free license agreement.
As such, these sketches are provided for personal/hobby use only, not for commercial purposes.
